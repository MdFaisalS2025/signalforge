# evals

Replay and evaluation harness.

- `scenarios/` — fault manifests and expected results (unique id, fault trigger,
  expected evidence, accepted causes, allowed/prohibited actions, latency bounds).
- `graders/` — deterministic and model-based graders.
- `reports/` — generated scorecards (gitignored; regenerated per run).
